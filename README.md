# USR Advisory & Consultancy Services — Professional Website

Premium responsive static website for GitHub Pages.

### Included
- Supplied company logo asset and header crop
- Premium black / gold / ivory consulting visual system
- Detailed services, industries, approach, engagement models, partner ecosystem and contact sections
- Responsive mobile navigation
- No paid backend required

### Before publishing
Replace `YOUR_EMAIL@example.com` in `index.html` with the real company email.

### GitHub Pages
For the current project-site repository, keep `index.html` at the repository root and publish `main` / root.

For a clean organization URL such as `https://usradvisory.github.io/`, the GitHub organization must be `usradvisory` and the repository must be named `usradvisory.github.io`.

A custom domain can be connected later through GitHub Pages.
